# Gated Development Manifesto

Software agents should be powerful without being unconstrained.

We value:

- **context over guesswork**;
- **small verified steps over broad speculative execution**;
- **explicit boundaries over implied scope**;
- **working checkpoints over long autonomous runs**;
- **architecture that anticipates the future without implementing it prematurely**;
- **reviewability over raw change volume**.

We believe an agent should understand more than it is authorized to change.

We believe non-goals are first-class requirements.

We believe every task should define how completion is proven.

We believe a roadmap is context, not permission.

We believe the repository's current state is more trustworthy than an old plan.

We believe autonomous coding becomes more useful when execution is gated by explicit intent.

## The operating sentence

> Give the agent the whole map, but only one key at a time.

## The engineering version

> Global context. Local authority. Explicit gates.
