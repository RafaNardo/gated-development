# Milestone Template

```md
# M<X> — <Milestone name>

## Outcome
What capability should exist when this milestone is complete?

## Why now
Why does this milestone come at this point in the roadmap?

## Scope
Included:
- ...

Excluded:
- ...

## Constraints
Stable architecture/product constraints that every task in this milestone must respect.

## Tasks
- M<X>-001 — ...
- M<X>-002 — ...
- M<X>-003 — ...

## Milestone acceptance criteria
- [ ] ...
- [ ] ...
- [ ] ...

## Exit review
Before opening the next milestone:
- inspect the repository's actual state;
- compare it against the roadmap assumptions;
- record new decisions;
- adjust future tasks if necessary.
```

A milestone groups a coherent capability. It should not become a license for the agent to implement all future work at once.
